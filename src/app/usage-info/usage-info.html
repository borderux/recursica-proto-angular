← Back to Prototypes How to Use Every prototype in this app can define one or more stories — named variants that swap in different data or API behavior, like a normal load, an empty state, or an error. Opening the stories panel Add ?story or ?stories to the end of any prototype's URL to open the story picker. It lists every story available for that prototype by name and description — click one to switch to it. @if (firstPrototypeSlug()) { Open the stories panel } Linking directly to a story Add ?story=<id> (for example, ?story=2) to jump straight to a specific story without opening the picker — handy for sharing a link to one exact state.
